# 공고문 근거로 조건을 비교하는 방법

## 1차 검토 범위

2026-11-25에 청약홈 공식 첨부 PDF 원본을 내려받아 텍스트와 해당 페이지 이미지를 대조했다.

| 공고번호 | 공고 | 검토한 입력 조건 | 주요 추가 확인 사항 |
|---|---|---|---|
| 2026940257 | 강동한강 디에트르 임의공급 | 거주 시도, 청약통장 불필요 | 나이·미성년자 예외·실제 국내 거주·미확정 조건 |
| 2026950097 | 힐스테이트 오송레이크센트럴 2단지 | 거주 시도, 청약통장 불필요 | 개인·법인 구분, 나이, 신청금, 해당 공고 내 1인 1실 제한 |
| 2026910304 | 더샵 분당하이스트 무순위 2차 | 무주택세대구성원, 수도권 거주, 청약통장 불필요, 세대주 한정 아님 | 세대 범위·주택 소유 예외·국적·해외 체류·당첨 이력·제한 기간 |

원본 URL, SHA-256, 공고일, 근거 쪽수, 짧은 발췌, 검토일, 유효기간은 [검토 데이터](../data/eligibility-rules.json)에 기록했다. PDF 전체는 재배포하지 않는다. 공고문에 명시되지 않았다고 해서 ‘요건 없음’으로 해석하지 않는다. 법인과 미성년자 예외 등은 자동 판정 범위에 포함하지 않는다.

## 동작

- 수집 단계에서 공고번호와 주택관리번호, 공고일이 일치해야 한다.
- 정기 수집 때마다 공식 PDF를 다시 받아 해시를 비교한다. 해시 변경·접근 실패·유효기간 만료 시 자격 근거를 해제한다. 일정 데이터 수집은 계속할 수 있다.
- 원본을 대조한 뒤 30시간 이상 지나면 브라우저에서도 근거 사용을 중지한다.
- 주택 수·정확한 거주 시도·원 단위 예치금·세대주 여부를 조건별로 비교한다. 미입력과 0원은 구별한다. 이전 버전의 자동 기본값은 관심 목록만 이관하고 조건은 다시 입력받는다.
- 알고 있는 조건이 미달이면 다른 조건이 미확인이어도 입력 조건 미달로 표시한다. 근거가 없거나 입력이 없다는 이유만으로 미달이라고 표시하지 않는다.
- 네 입력 조건이 부합해도 최종 청약 신청 자격을 확정하지 않는다. 나이·국적·소득·자산·가입기간·해외 체류·재당첨 제한 등은 공고별 추가 확인 사항으로 표시한다.
- 발표일 중복은 날짜 겹침 알림이다. 날짜만으로 모든 유형의 중복신청 유효·무효를 판정하지 않는다.

## 운영

검토하지 않은 공고에는 자격을 추정해 채우지 않는다. 검토 데이터에 새 공고를 추가하려면 공식 공고문 전체의 관련 조항·각주·예외를 확인하고, 원본 해시와 페이지를 기록한다. 기본 검토 유효기간은 최대 31일이며 변경·정정 공고가 있으면 다시 검토해야 한다. 현재는 공고문 문장을 자동 추출해 법률 요건으로 변환하는 시스템이 아니다.

검증 명령:

```powershell
python -m unittest discover -s tests -v
node --test tests/ui-status.test.cjs
node --check app.js
```

화면 테스트는 날짜마다 달라지는 운영 공고 수·이름에 의존하지 않는 고정 예제를 사용한다. 판정 테스트는 공개 앱에 포함되는 동일한 함수를 사용한다.

## 공고문 자동 분석 (AI)

사람이 검토하지 않은 공고는 `scripts/auto_eligibility.py`가 정기 수집 직후 자동으로 분석한다.

1. 청약홈 상세 페이지의 '모집공고문 보기' 링크에서 같은 공고번호의 PDF를 찾는다.
2. PDF 텍스트를 쪽별로 추출해 자격 관련 쪽 위주로 Claude(`claude-opus-5-5`)에 보낸다. 스캔본처럼 텍스트가 없으면 건너뛴다.
3. Claude는 주택 수·거주 시도·예치금·세대주 조건을 근거 문장과 쪽 번호와 함께 JSON으로 돌려준다. APT 일반공급은 1순위 기준이다.
4. **근거 문장이 PDF 텍스트에 실제로 있어야만** 그 조건을 쓴다. 없으면 버리고 '확인 필요'로 남긴다. 쪽 번호가 틀리면 실제 쪽으로 고친다.
5. 결과는 `data/auto-eligibility.json`에 PDF 해시와 함께 저장한다. PDF가 바뀌거나 31일이 지나면 다시 분석한다. 한 번 실행에 새 분석은 최대 15건이다.

예치금이 '지역·면적별 예치금액' 기준인 민영주택은 주택공급에 관한 규칙 별표 2의 금액표로 사용자의 거주 시도와 가장 작은 주택형 면적에서 필요한 금액을 계산한다.

화면에는 'AI 공고문 분석' 표시와 분석일, 근거 문장, 원문 쪽 링크를 함께 보여 준다. 사람이 검토한 근거가 있으면 그것이 우선한다.

설정: GitHub 저장소 Actions Secret에 둘 중 하나를 등록한다. 둘 다 있으면 API 키를 쓴다. 둘 다 없으면 새 분석은 하지 않고 저장된 분석만 다시 적용한다.

- `CLAUDE_CODE_OAUTH_TOKEN`: Claude Pro·Max 구독. PC 터미널에서 `claude setup-token`을 실행해 나온 토큰(1년 유효). 워크플로가 Claude Code CLI를 설치해 `claude -p`로 분석한다. 구독 사용 한도를 함께 쓴다.
- `ANTHROPIC_API_KEY`: Anthropic Console에서 발급한 API 키. 사용량만큼 과금된다.

Anthropic 안내에 따르면 구독 인증은 개인의 일반적인 Claude Code 사용을 위한 것이고, 다른 사람에게 제공하는 제품·서비스에는 API 키를 쓰도록 되어 있다([Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)). 개발·테스트 단계에서는 구독 토큰으로 돌리고, 공개 출시·유료화 전에는 API 키로 바꾼다.
